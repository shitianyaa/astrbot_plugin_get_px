# 项目概览

## 插件定位

`astrbot_plugin_get_px` 是一个面向 AstrBot 的 Pixiv 图片获取与签到系统插件。它的核心职责是：

- 从 Lolicon API 和 Pixiv API 获取插画作品并发送到聊天
- 提供每日签到系统，包含金币、好感度、连续签到和成就系统
- 生成签到卡片，支持多种主题和在线背景
- 提供金币商店，支持购买好感度加持、签到主题和背景刷新
- 管理作品去重索引、内容安全过滤和作品黑名单
- 支持群签到排行榜和趋势查询
- 提供 Plugin Pages 管理界面

## 当前入口

用户入口（发图）：

- `/来点图`、`/来点好图`、`/来点涩图`
- `/p <关键词>`
- `/pid <作品ID>`
- `/随机推荐`

用户入口（签到）：

- `/签到`、纯文本"签到"
- `/签到状态`、`/签到成就`、`/签到日历`
- `/签到排行`
- `/签到商店`
- `/签到管理`
- `/签到帮助`

管理入口：

- Plugin Pages 管理中心（群排行、成员编辑、内容安全、签到数据管理）

运行入口：

- 插件自身入口是本仓库根目录 `main.py`
- 本地集成验证通常运行上层 AstrBot 工程入口

## 当前能力边界

插件负责：

- Pixiv 作品搜索、下载和发送
- 图片质量选择和降级策略
- Lolicon 图片反代轮换
- 签到流程、奖励计算和卡片渲染
- 签到数据持久化（SQLite）
- 金币商店商品购买和加持管理
- 群签到排行与趋势查询
- 作品去重索引（多自然日）
- 内容安全词过滤和作品黑名单
- Plugin Pages 管理界面
- 节假日数据更新与查询
- 签到问候（本地事件、一言 API、AI 模型）

插件不负责：

- 提供通用 Pixiv 浏览器
- 长期存储完整作品元数据
- 跨机器同步签到数据
- 替代 AstrBot 的消息发送和 T2I 服务
- 实时监控 Pixiv 作者动态

## 对维护者最重要的事实

- `main.py` 是入口和编排层，不应重新堆放业务细节。
- `pixiv/` 是 Pixiv 作品获取、下载和发送层。
- `checkin/` 是签到系统业务层。
- `plugin_api/` 是 Plugin Pages 后端 API 层。
- `_conf_schema.json` 是配置字段真源；README 和 docs 必须跟它同步。
- 作品去重索引在 SQLite 中，按自然日分区，保留最近 N 天。
- 签到数据在 SQLite 中，包含用户资料、奖励记录、群排行和卡片缓存。
- 图片下载使用实时字节计数，返回 `(path, size)` 元组。
- Lolicon 图片反代配置支持多个 origin，按顺序轮换尝试。
- 签到卡片渲染依赖 AstrBot 的 HTML/T2I 能力。
- 内容安全词和作品黑名单在 SQLite 中，支持通配符匹配。
- 节假日数据来自 `holiday-cn`，每 180 天自动更新一次。
# 分群内容安全

管理中心允许按群独立设置普通分级限制和内置安全词。未配置群及私聊延续严格默认行为；自定义安全词和作品 ID 黑名单保持全局作用域。关闭普通分级限制时，Lolicon 与 Pixiv 回退使用一致的普通/R18 混合策略。
