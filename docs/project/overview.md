# 项目概览

## 插件定位

`astrbot_plugin_get_px` 是一个面向 AstrBot 的 Pixiv 图片获取与签到系统插件。它的核心职责是：

- 按配置优先从 Lolicon API 或 Pixiv 获取插画，请求失败或无结果时尝试另一源并发送到聊天
- 提供每日签到系统，包含金币、好感度、连续签到和成就系统
- 生成签到卡片，支持多种主题和在线背景
- 提供金币商店，支持购买好感度加持、签到主题和背景刷新
- 管理作品去重索引、内容安全过滤和作品黑名单
- 支持群签到排行榜和趋势查询
- 提供 Plugin Pages 管理界面

## 当前入口

用户入口（发图）：

- `/p [标签] [数量]`：有标签搜索，无标签随机取图
- 模型通过 `get_px_image` 向当前聊天取图，`get_px_artworks` 查询公开作品及候选，`get_px_users` 查询作者，`get_px_context` 只读当前用户余额与限制；随包 [Skill](../../skills/get-px-image/SKILL.md) 提供参数与状态说明，不依赖 MCP。

命令保留正常账单，余额不足时终止；模型工具正常取图不发账单，按可负担数量缩减，余额读取失败时拒绝。两者共用取图与消费规则；工具默认逐张直发，仅选择 `auto` 时使用合并阈值，用户明确要求时可选择合并转发。

用户入口（签到）：

- `/签到`、纯文本“签到”、`/签到帮助`
- `/签到状态`、`/签到成就`、`/签到日历 [YYYY-MM]`、`/刷新背景`
- `/签到生日`、`/签到称号`、`/签到排行`、`/签到商店`、`/签到主题`、`/签到管理`

完整参数见 [指令参考](../user/commands.md)。

管理入口：

- Plugin Pages 管理中心（群排行、成员编辑、内容安全、会话策略、签到数据与缓存管理）

运行入口：

- 插件自身入口是本仓库根目录 `main.py`
- 本地集成验证通常运行上层 AstrBot 工程入口

## 当前能力边界

插件负责：

- Pixiv 作品搜索、下载和发送
- 图片质量选择和降级策略
- Lolicon 图片反代轮换
- 签到流程、奖励计算和卡片渲染
- 签到数据持久化（SQLite）
- 金币商店商品购买和加持管理
- 群签到排行与趋势查询
- 作品去重索引（多自然日）
- 内容安全词过滤和作品黑名单
- Plugin Pages 管理界面
- 节假日数据更新与查询
- 签到问候（本地事件、一言 API、AI 模型）

插件不负责：

- 提供通用 Pixiv 浏览器
- 长期存储完整作品元数据
- 跨机器同步签到数据
- 替代 AstrBot 的消息发送和 T2I 服务
- 实时监控 Pixiv 作者动态

## 对维护者最重要的事实

- `main.py` 是入口和编排层，不应重新堆放业务细节。
- `pixiv/` 是 Pixiv 作品获取、下载和发送层。
- `checkin/` 是签到系统业务层。
- `plugin_api/` 是 Plugin Pages 后端 API 层。
- `tools/` 提供模型调用入口，`skills/` 提供随包调用说明，共享 `pixiv/` 的执行流程。
- `_conf_schema.json` 是配置字段真源；README 和 docs 必须跟它同步。
- 作品去重索引在 SQLite 中，按自然日分区，保留最近 N 天。
- 签到正式数据在 `checkin.sqlite3`；卡片 JPEG 和背景摘要按日期存放在 `checkin_card_cache/`，不属于 SQLite 缓存。
- 图片下载使用实时字节计数，返回 `(path, size)` 元组。
- Lolicon 图片反代配置支持多个 origin，按顺序轮换尝试。
- 签到卡片渲染依赖 AstrBot 的 HTML/T2I 能力。
- 全局自定义安全词和作品黑名单在 `image_index.sqlite3`；会话独立规则在配置中。安全词支持通配符匹配。
- 图片去重按会话、图源和标签隔离；相同用户有效安全规则一致时可以跨群复用当天签到卡。两者的身份不同，详见 [缓存与去重](cache-and-dedupe.md)。
- 节假日来自 `holiday-cn`，保存在 `holiday_calendar.json`；初始化时检查版本、年份、180 天刷新间隔和 24 小时失败重试窗口，当前没有定时刷新任务。

## 会话内容安全

群聊与私聊分别按群 ID／用户 ID 保存普通分级、内置安全词和独立屏蔽词／作品黑名单。内置安全词开启时使用内置词与全局列表，忽略独立列表；关闭时仅使用当前会话独立列表。未配置会话或读取异常采用严格默认策略。关闭普通分级限制时，Lolicon 与 Pixiv 使用一致的普通／R18 混合策略。配置细节见 [配置说明](configuration.md#会话内容安全策略)。
