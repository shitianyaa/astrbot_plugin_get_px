## 发图

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/p [标签] [数量]` | 按标签搜索并发送图片，支持含空格的多词标签 | `/p 初音ミク 3` |
| `/p [数量]` | 无标签时随机发送图片 | `/p 5` |

命令发图调用正常返回或发送超时，均按张扣除 `p_coin_cost` 金币（`0` 表示免费）；超时不重发，即使最终未出图也不退款。金币不足时仅提醒、不进入取图；下载／构建失败和其他发送异常不扣币。构建及发送异常只记日志，不补发聊天失败提示，正常结算消息保留。详见 [发送流程](../project/architecture.md#onebot-图片发送)。

发图按 `preferred_image_source` 下拉选项优先请求 Lolicon（默认）或 Pixiv；请求失败或无结果时尝试另一源。Lolicon 有标签时搜索、无标签时随机；Pixiv 有标签时搜索、无标签时推荐。Pixiv 需配置 `pixiv_refresh_token`，留空时直接使用 Lolicon。候选被过滤、去重或下载失败不触发换源。Lolicon 请求地址固定，不再提供地址配置。

普通发图、正式签到和刷新背景共享图片去重索引。`dedupe_days` 可设置最近 `0–7` 个北京时间自然日，`1` 只覆盖当天，不是滚动 24 小时；同群成员共享，不同群、私聊用户、标签和图片源相互隔离。因此跨会话或跨标签再次抽到同图属于当前规则允许的情况，详细边界见 [缓存与去重](../project/cache-and-dedupe.md)。Lolicon 图片地址不可用时，可在 `lolicon_image_proxy_origins` 中按行配置多个图片反代 origin；该配置不代理 Lolicon API 或 Pixiv 登录。

普通发图按配置画质取图，超过大小上限或下载失败就换作品，不降画质；最多取 3 批、尝试 20 张作品，不足时发送已找到的图片。被跳过的候选不扣费。

## 模型原生取图

模型可调用 `get_px_image` 向当前聊天取图，`get_px_artworks` 免费查询公开作品与候选，`get_px_users` 免费查询作者，`get_px_context` 只读当前用户余额与取图限制。参数、状态与重试边界见 [随包 Skill](../../skills/get-px-image/SKILL.md)。

命令和模型工具共用数量上限、图源、安全、去重和收费规则。模型工具默认逐张直发，`auto` 才使用配置合并阈值；用户明确要求合并时可选 `forward`（仅 OneBot）。命令保留正常账单、余额不足时终止；工具正常取图不发账单，按可负担数量缩减，余额读取失败拒绝执行。数量缩减按返回原因解释，不猜测图库不足或标签失效。

模型入口支持作品直取与单页、榜单、作者、关联作品和明确 Pixiv 搜索。查询不发送、不扣费、不占去重，Pixiv 可真实续查，Lolicon 仅随机取样；明确 Pixiv 模式不跨源回退。指定作品可重取历史，但不绕过在途占用、安全、数量或费用。

用户问点赞或要挑热门图时，作品查询可传 `include_stats=true`，分别返回 `total_likes`、`total_bookmarks` 和 `total_view`。补查失败的字段为 null，保留候选与已有统计；查询不改变榜单顺序，不提供全站按热度排序。看日榜／周榜使用 ranking 查询，明确要求发图时才发送。用户未明确要求时禁止主动视觉识图，热度不代表画面质量。

同一事件可查询后发送，发送只执行一次，重复调用不新增发送或消费；追加取图需用户另发新消息。调用正常返回不证明用户已看到，送达未知不补发。

## 签到（管理员）

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/签到管理 预览` | 使用当前用户资料和问候配置预览卡片，不写入数据 | `/签到管理 预览` |
| `/签到管理 事件查看` | 查看全局签到事件 | `/签到管理 事件查看` |
| `/签到管理 事件添加 <年度\|单次> <日期> <名称>` | 添加年度或单次全局事件 | `/签到管理 事件添加 年度 07-11 相遇纪念日` |
| `/签到管理 事件删除 <ID>` | 按事件 ID 删除全局事件 | `/签到管理 事件删除 1` |
| `/签到管理 导出` | 管理员导出签到完整备份 | `/签到管理 导出` |

只输入某个指令组名（如 `/签到生日`、`/签到排行`、`/签到商店`、`/签到主题` 或 `/签到管理`）时，AstrBot 会显示对应层级的文字指令树；使用 `/签到帮助` 发送完整帮助图。文档使用默认前缀 `/`；实际前缀以 AstrBot 的 `wake_prefix` 配置为准。
